1. Create .env file and place your port to run the server.

```
PORT=3000
ORDER_THRESHOLD=10
```

2. Run DB server using json server as the in memory database

```
npm run server
```

3. Run the backend by issuing the command

```
npm run dev
```

4. To run the test script at the backend, open a separate terminal and issue the command
```
npm run test
```

5. For running the web app, clone the web app repo, install dependencies and run the web app

```
npm i
npm run dev
```
